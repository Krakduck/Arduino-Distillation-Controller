# Arduino-Distillation-Controller
# Автоматизированная система управления процессом дистилляции на Arduino (IoT)

Проект аппаратного контроллера на базе микроконтроллера Arduino для автоматизации и контроля безопасности процесса ректификации/дистилляции. Система осуществляет непрерывный мониторинг температурных показателей в критических узлах аппарата, выводит данные на TFT-дисплей и управляет нагревательным элементом (печью) для предотвращения аварийных ситуаций.

## 🚀 Функционал
* **Многоточечный термоконтроль:** Опрос аналоговых датчиков температуры (куб, верх колонны, ТСА) с программным сглаживанием показаний (алгоритм усреднения по 50 замерам) и округлением.
* **Интеллектуальная безопасность:** Автоматическое аварийное отключение нагревательного элемента при превышении критического порога температуры или при сбое в системе охлаждения.
* **Интерактивный интерфейс (HMI):** * Вывод технологических параметров в реальном времени на цветной графический TFT-дисплей `ILI9341` через шину SPI.
  * Управление режимами, настройка лимитов и ввод данных с помощью матричной клавиатуры 4x4 (`Keypad`).
* **Логика таймингов:** Ведение отсчета времени технологических этапов без блокировки основного цикла (использование `millis()` вместо `delay()`).

## 🛠 Аппаратная платформа и технологии
* **Микроконтроллер:** Arduino (разработка на C/C++)
* **Дисплей:** Adafruit ILI9341 (SPI интерфейс)
* **Ввод данных:** Матричная клавиатура 4x4
* **Датчики:** NTC-термисторы (расчет температуры по уравнению Стейнхарта-Харта)
* **Используемые библиотеки:** `Adafruit_ILI9341.h`, `Adafruit_GFX.h`, `SPI.h`, `Keypad.h`

## 📊 Структура меню и управления
* **Клавиша 'C':** Переключение состояния нагревательного элемента (Вкл/Выкл вручную).
* **Клавиша 'A/B':** Навигация в консоли.
* **Клавиша '*': Сброс ввода.
* **Клавиша '#':** Ввод.
* Настройка критических порогов температуры через консоль ввода.
