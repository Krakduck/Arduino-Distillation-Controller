# Arduino Distillation Controller
Автоматизированная система дистилляции. Проект создавался для автоматизации самогоноварения. Он умеет следить за температурой, регулировать ее, запускать умный процесс отбора, автоматически отключаться.

**Код разрабатывался для своих личных нужд, поэтому имеет нелогичные и неоптимальные решение. Проект находится в архивном состоянии и не предполагался к дальнейшему рефакторингу.**

# Стек
* IDE: Arduino IDE 1.8x
* Микроконтроллер: Arduino Mega 2560
* Библиотеки:
  * Adafruit_ILI9341.h
  * SPI.h (стандартная)
  * Keypad.h 

# Подключение
 * пины {22,23,25,27}, {29,31,33,35} отвечают за клавиатуру
 * пины 5,6,7 отвечают за реле
 * пин 9 - dc на дисплее, 8 -rst, cs - не подключаем, остальные все стандартные
 
# Подключение
Скачайте файл .ino и откройте его в arduni ide, при отсутствии нужных библиотек, установите их.
